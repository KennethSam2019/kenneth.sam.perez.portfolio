# Kenneth Sam Perez — Developer Portfolio

A professional portfolio for software engineering and technical leadership opportunities.

**Website:** https://kennethsam2019.github.io/kenneth.sam.perez.portfolio/

## Content

- Selected project: NexaCode Tech, with its verified technology stack and engineering capabilities
- Technical skills grouped into backend/data, web/mobile, and engineering practice
- Career progression and an automatically calculated experience total
- Professional introduction, education, and LinkedIn contact link

## Development

Open `index.html` in a browser. The page is static and includes its styles and experience-counter script. There is no build step or external dependency.

GitHub Pages publishes the repository root from `main`. Update `index.html` and push to deploy. The `.nojekyll` file keeps it a plain static site.

The experience counter reads `data-start` and `data-end` from career entries (`YYYY-MM` or `present`), counts completed months in Asia/Manila, and merges overlapping periods. It updates on page visits, visibility changes, and hourly while open.

The page uses text and layout to highlight professional qualifications. Legacy artwork in `assets/` is retained as source material and is not loaded by the website.
